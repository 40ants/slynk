## Usage

This library provides a little helper, used in `40A`nts webservices.
it does the following things:

* Starts Slynk server in there is `SLYNK`_`PORT` env variable.
* Setup logging for connected Slynk connection. It uses [`40ants-logging`][970f] system for configuration.
* If `FASL`_`DIR` env variable is set, then fasl files, produced during compilation,
  are written into this directory (mirroring the structure of sources) instead
  of being placed near the sources. This is useful when the server runs under
  another user or has a read-only filesystem.

### [function](a23b) `40ants-slynk:start-slynk-if-needed`

Use this function before starting the backend server.

If `SLYNK`_`PORT` environment variable is set, then this function
will create a Slynk server on that port and localhost interface.
To change an interface, set `SLYNK`_`INTERFACE` environment variable.

If `FASL`_`DIR` environment variable is set, then fasl files, produced
during compilation, will be written into that directory (mirroring
the structure of sources) instead of being placed near the sources.
